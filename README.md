# Programas Python
## Exercícios para aprendizado de python reúnidos em um Repositório

### Introdução Geral
Nos exercícios, os conceitos de lógica de programação e funcionamento da linguagem foram, progressivamente, compreendidos e desenvolvidos, tais como: 
* Variáveis e Tipos
* Operações matemáticas e Operadores Lógicos
* Estrutura Condicional
* Laços de repetição
* Listas, Tuplas e Dicionários

### Arquivos PE
São exercícios do livro "Fundamentos da programação de computadores: algoritmos, PASCAL,C/C++ (padrão ANSI) e JAVA", realizados individualmente e depois corrigidos pelo professor, durante as aulas de programação de computadores no IFSP. A letra P corresponde à página e E, ao número do exercício.

### Arquivos Nome
Exercícios propostos no curso de Desenvolvimento Senac, na unidade curricular de Aplicações Desktop. O arquivo recebe como nome o tema da atividade.
